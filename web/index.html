2. Settings

Leave it blank and one is picked for you. Everyone who builds the same seed and settings gets the same game (the seed shows on the title screen, and the file screen shows a four-icon code to compare).

Quest shapes keep each level's outline of rooms; Legend of Link makes its doors, rooms, enemies and items. With a quest, its two grids stay as they are and two Legend of Link grids hold the shrines. Mixed (seeded): one quest's levels 1-6 grid and another quest's 7-9 grid, each level its quest's own; the shrines come from two more maps, each a Legend of Link grid or a third quest's 1-6 grid. (Unseeded Mixed: each level from any set, the shrines Legend of Link maps or random shapes.)

Normally the build decides everything dungeon-related from the seed - the entrances and every level and shrine (layout, rooms, enemies, boss, cellar items and old men cards) - so a seed is one fixed game anyone can share; a blank seed gets one picked. Unseeded: the game rolls these itself when a file starts and as Link finds them, as before (a blank seed: a different game on every new file).

Scrambles the map, dungeon and cave data inside the ROM, so map viewers and ROM tools can't show the seed. Race Roms get their own seed code.

Deals the dungeon and overworld enemies into new groups (Moblins in dungeons, Stalfos outside...). Wallmasters, Vires, Like Likes, Zols, Lanmolas, Wizzrobes, Gels and Keese stay in dungeons; Octoroks, Peahats, Leevers, boulders, Zoras, Ghinis and Armos stay outside. Then the overworld screens' monsters are dealt to other screens (Zoras and Ghinis stay where they are; screens without monsters keep none).

Upgrades turn up outside the upgrade caves too: one in the dungeons' stairs and floor items (it comes sooner as Link levels up), and more as the game goes on. Link still keeps at most three. Seeded games only.

These only change how the game looks and plays for you: the seed, its code and the game stay the same.
